# Audit S3 Buckets for Public Access and Notify

## Deployment
1. Create the least-privilege IAM role described in the submission report.
2. Create the Lambda function with Python 3.12.
3. Configure the environment variables listed in the report.
4. Paste `lambda_function.py`, deploy, and test.
